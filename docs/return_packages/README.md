# Return Packages

This directory is the canonical home for ScoutZero return packages.

## Where to Put New Packages

New return packages go under `docs/return_packages/<area>/`. Create the area folder when needed. Use underscore naming only — do not create `return-packages` paths.

Common area names: `architect/`, `scouting/`, `tradeMachine/`, `team-scrape/`, `typescript/`, `workspace-cleanup/`, `general/`.

## Naming And Content Rules

- See `../workspace-rules/RETURN_PACKAGE_STANDARD.md` for the full standard.
- Every return package must include: files changed, commands run, commands skipped, and validation results.
- Return packages are delivery evidence — not permanent feature docs, not working docs.
