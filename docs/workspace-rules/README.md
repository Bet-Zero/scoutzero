# Cursor Rules Plan

This directory contains the plan and chunk structure for managing Cursor workflow rules and processes.

## Structure

- `plan.md` — Main plan document describing intent, scope, and current state
- `chunks/` — Individual chunk files for actionable steps
- `chunks/chunk_template.md` — Template for creating new chunks

## Usage

When working on Cursor-related tasks:

1. Reference `plan.md` for overall context
2. Create chunks in `chunks/` for specific work items
3. Use workspaces in `cursor_work/<slug>/` for temporary files during execution
4. Update `plan.md` with chunk status and revisions
