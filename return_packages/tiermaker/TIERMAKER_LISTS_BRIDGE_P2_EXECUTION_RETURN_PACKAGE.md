## Summary

Implemented owner-only "Save as List" functionality for both TierMakerBoard (standard tiers) and TieramidBoard (pyramid). This allows owners to explicitly export their curated tier boards into a `lists/{listId}` document, enabling interoperability with Ranker + Lists features.

### Key Features

- **Owner-only button**: "Save as List" visible only to owners, hidden in screenshot mode
- **Defense in depth**: Handler refuses execution if non-owner somehow triggers it
- **List creation**: Uses existing `createList` + `saveList` from `listHelpers.js`
- **Correct order**: Exported `playerOrder` respects board traversal order (tier/row top → bottom, Pool appended last)
- **No auto-save**: No new Firestore writes occur without explicit user action

## Exact Conversion Rules Used

### Standard TierMaker (tiers → playerOrder)

```
1. Traverse `tierOrder` from first to last (excluding Pool)
2. For each tier, preserve left-to-right array order
3. Append `tiers["Pool"]` IDs at the end
4. Dedupe: first occurrence wins
5. Filter: remove falsey/invalid IDs
```

**Example:**

```javascript
tiers = { S: ['p1', 'p2'], A: ['p3'], Pool: ['p4', 'p5'] };
tierOrder = ['S', 'A', 'Pool'];
// Result: playerOrder = ['p1', 'p2', 'p3', 'p4', 'p5']
```

### Tieramid (rows → playerOrder)

Same logic with `rows`/`rowOrder`:

```
1. Traverse `rowOrder` from first to last (excluding Pool)
2. For each row, preserve left-to-right array order
3. Append `rows["Pool"]` IDs at the end
4. Dedupe: first occurrence wins
5. Filter: remove falsey/invalid IDs
```

**Example:**

```javascript
rows = { Row1: ['p1'], Row2: ['p2', 'p3'], Pool: ['p4'] };
rowOrder = ['Row1', 'Row2', 'Pool'];
// Result: playerOrder = ['p1', 'p2', 'p3', 'p4']
```
