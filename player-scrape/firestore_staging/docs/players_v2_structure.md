The files generated by `player-scrape/firestore_staging/stage_player.ts` map to the following Firestore hierarchy. This example is derived from the staged output for `toumani_camara`.

## Subcollection `contracts/{contract_N}`

Each contract is stored chronologically using ordinal IDs (`contract_1`, `contract_2`, …). The payload mirrors the normalized contract JSON with an added `metadata` block.

```json
{
  "contractType": "ROOKIE CONTRACT",
  "isExtension": false,
  "signingTeam": "PHX",
  "startSeason": "2023-24",
  "endSeason": "2026-27",
  "contractLength": 4,
  "totalValue": 7639302,
  "averageAnnualValue": 1909825.5,
  "salariesByYear": [
    { "season": "2025-26", "salary": 2221677, "guaranteed": true },
    { "season": "2026-27", "salary": 2406205, "guaranteed": false, "option": "TO" }
  ],
  "freeAgency": { "type": "UFA", "year": 2027, "optionType": "TO" },
  "metadata": {
    "startSeason": "2023-24",
    "endSeason": "2026-27",
    "isCurrent": true,
    "label": "ROOKIE CONTRACT"
  }
}
```

## Subcollection `seasons/{seasonId}`

One document per stats season (as scraped). The example has only `2025-26`.

```json
{
  "team": "POR",
  "stats": {
    "PTS": 12.4,
    "AST": 3.3,
    "REB": 5,
    "...": "..."
  },
  "meta": {
    "statsSeasonTag": "2025-26",
    "statsCarryOver": false,
    "provenance": "nba_stats",
    "lastStatsUpdate": { "_seconds": 1762432576, "_nanoseconds": 0 }
  }
}
```

## Subcollection `views/contracts`

Compact timeline used for cap-table style displays. Covers the current season plus five future seasons.

```json
{
  "seasons": [
    { "season": "2025-26", "salary": 2221677, "sourceContractId": "contract_1" },
    { "season": "2026-27", "salary": 18080358, "sourceContractId": "contract_2" },
    { "season": "2027-28", "salary": 19526786, "sourceContractId": "contract_2" },
    { "season": "2028-29", "salary": 20973214, "sourceContractId": "contract_2" },
    { "season": "2029-30", "salary": 22419642, "sourceContractId": "contract_2" },
    { "season": "2030-31", "salary": 0 }
  ],
  "freeAgentYear": 2030,
  "freeAgentType": "UFA",
  "birdRights": { "status": "Bird", "eligibleFor": ["Bird Exception"] },
  "currentSalary": 2221677,
  "yearsRemaining": 5,
  "averageAnnualValue": 12319014
}
```

Entries inside `seasons[]` only include `nonGuaranteed` or `option*` fields when applicable.

## Evaluations (Placeholder)

`players_v2/{playerId}/evaluations/{doc}` is not populated by the scraper; the site writes these documents. The expected shape is defined in `src/schemas/players_v2.ts` (`EvaluationDocZ`).

## Quick Reference

- **Root fields:** `bio`, `createdAt`, `updatedAt`
- **Subcollections:** `contracts`, `seasons`, `views/contracts`, `evaluations` (frontend-managed)
- **Ordinal IDs:** contract documents use `contract_N`; contract views refer back via `sourceContractId`.

For full JSON files corresponding to this example, run the staging script and inspect `player-scrape/firestore_staging/output/players_v2/` (git-ignored).
