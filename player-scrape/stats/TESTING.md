# Stats Regression Testing Guide

This guide explains how to set up and run regression tests for stats scraping.

## Overview

Regression tests ensure the stats parser produces consistent output. Tests compare parsed output from pinned NBA API snapshots against expected fixtures, ignoring volatile fields like `USG%` and timestamps.

**Test Players:** `luka_doncic`, `jalen_wilson`, `jordan_poole`, `austin_reaves`

## Setup Workflow

### Step 1: Capture Snapshots

For each regression test player, capture the NBA API JSON responses:

```bash
# Capture snapshots for a player (requires NBA_ID)
PLAYER_ID="luka_doncic" NBA_ID="1629029" SEASON="2024-25" \
  npx tsx player-scrape/stats/scripts/_dev/capture_snapshot.ts
```

This creates:
- `snapshots/luka_doncic_base.json` - Player stats API response
- `snapshots/luka_doncic_team.json` - Team stats API response (optional, for USG%)

**Note:** If `NBA_ID` isn't set, the script will try to resolve it from `player-scrape/shared/_artifacts/outputs/player_index.json`.

### Step 2: Generate Fixtures

After capturing snapshots, generate the expected fixture files:

```bash
# Generate fixture from snapshot
PLAYER_ID="luka_doncic" \
  npx tsx player-scrape/stats/scripts/_dev/generate_fixture.ts
```

This creates:
- `fixtures/luka_doncic.snapshot.json` - Expected normalized output

The fixture is generated by parsing the snapshot and pruning volatile fields (USG%, timestamps).

### Step 3: Run Regression Tests

Run all regression tests:

```bash
npm run regress:stats
```

Or directly:

```bash
npx tsx player-scrape/stats/scripts/_dev/run_regress.ts
```

The test will:
1. Read each player's snapshot from `snapshots/{playerId}_base.json`
2. Optionally read team snapshot from `snapshots/{playerId}_team.json`
3. Parse the stats
4. Compare against `fixtures/{playerId}.snapshot.json`
5. Report pass/fail for each player

If a test fails, it will write:
- `output/{playerId}.actual.json` - What was actually produced
- `output/{playerId}.expected.json` - What was expected

## Complete Setup Example

Here's the full workflow for setting up a new test player:

```bash
# 1. Capture snapshots (you'll need the NBA ID)
PLAYER_ID="luka_doncic" NBA_ID="1629029" SEASON="2024-25" \
  npx tsx player-scrape/stats/scripts/_dev/capture_snapshot.ts

# 2. Generate fixture
PLAYER_ID="luka_doncic" \
  npx tsx player-scrape/stats/scripts/_dev/generate_fixture.ts

# 3. Verify it works
npm run regress:stats
```

## Adding a New Test Player

1. Add the player ID to `REGRESSION_FIXTURES` in `scripts/config.ts`
2. Capture snapshots using `scripts/_dev/capture_snapshot.ts`
3. Generate fixture using `scripts/_dev/generate_fixture.ts`
4. Verify with `npm run regress:stats`

## Validation

You can also validate a specific output file:

```bash
# Validate the last generated output
npx tsx player-scrape/stats/scripts/validate_stats.ts

# Or specify a file
PLAYER_FILE="luka_doncic.json" TEAM_CODE="DAL" \
  npx tsx player-scrape/stats/scripts/validate_stats.ts
```

## Notes

- **Snapshots are committed to git** - These are the pinned test data
- **Fixtures are committed to git** - These are the expected outputs
- **USG% is ignored** - Comparisons prune USG% since it depends on team data
- **Timestamps are ignored** - `meta.lastStatsUpdate` is pruned from comparisons
- **Team snapshots are optional** - Only needed if you want USG% computation

## Troubleshooting

**"Could not determine season from snapshot"**
- The snapshot might not have a `SEASON_ID` field. Check the API response structure.

**"NBA_ID not found"**
- Set `NBA_ID` env var, or ensure player is in `player-scrape/shared/_artifacts/outputs/player_index.json`

**Test failures**
- Check `output/{playerId}.actual.json` vs `output/{playerId}.expected.json`
- Verify the parser hasn't changed
- If expected output changed legitimately, regenerate the fixture
