# Docs Archive

This directory stores retained historical documentation that is no longer an active source of truth.

Use active documentation under `docs/` and active working material under `docs/_working/`.

Documentation placement and lifecycle rules are defined in:

- `docs/workspace-rules/DOCUMENTATION_STRUCTURE_STANDARD.md`

## Current Archived Areas

- `_working/` - archived working-doc clusters from prior cleanup phases
- `architect/` - historical Architect review, ship, audit, phase, and implementation-history docs moved from `docs/architect/`
- `architect-teams-plan/` - archived Architect planning/design bundle moved out of the active docs surface
- `reviews/` - one-off historical review docs moved out of active routing
- `team-scrape/` - historical team-scrape audit evidence moved from `docs/team-scrape/`
- `tradeMachine/` - historical trade-machine review and gap docs moved out of `docs/`
- `typescript/` - archived TypeScript campaign bundle moved out of the active docs root
