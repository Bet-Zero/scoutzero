# Architect Docs Archive

This directory stores historical Architect working material that is no longer
part of the active runtime/reference set.

Use active Architect docs under [docs/architect/README.md](../../../docs/architect/README.md)
first.

## Archived Here

This archive currently includes:

- planning-phase and implementation-phase working docs
- review trackers and issue logs
- ship-readiness / smoke / audit packages that are historical checkpoints, not
  current runtime references
- one-off phase plans and implementation summaries
- archived migration execution notes

## Current Cleanup Rule

These files were archived because they are primarily useful as historical
evidence or implementation history. If a file contained useful information, the
goal was to preserve the information only if it was still needed in active
docs, not to keep the original working file in the active folder by default.
